# 업다운 로드

초등 5~6학년 디지털 미디어 리터러시 수업용 보드게임입니다.
전통 뱀사다리놀이를 디지털 세계로 옮긴 게임입니다. 지름길은 "업로드", 미끄럼틀은 "다운로드"이고, 도착하는 칸마다 딜레마·돌발 퀴즈·돌발 상황이 나옵니다. 딜레마는 정답이 하나가 아닌 3지선다이며, 모둠이 고른 이유를 말하면 판단력 점수를 더 받습니다.

- 로그인 없음, 서버 없음, 개인정보 저장 없음 — 링크만 열면 바로 시작 (카드를 골고루 보도록 이 기기에 나온 카드 번호만 기억)
- 모둠당 기기 1대(태블릿 가로 / 휴대폰 세로)
- 표준 40칸(약 25분) / 압축 25칸(약 15분)
- 엔진과 카드팩을 분리해, 카드팩만 바꾸면 환경·인권·민주시민교육 등 다른 주제로 재사용

## 실행

- 가장 간단한 방법: `index.html`을 브라우저로 열기 (서버 없이도 동작)
- 수업용 링크: GitHub Pages 등 정적 호스팅에 폴더째 올리기
- 링크 옵션: `index.html?mode=short` (압축 모드), `?tokens=1` (말 개수), `?pack=폴더이름` (카드팩)

## 폴더 구조

```
index.html              진입 화면 (스크립트 순서: 설정 → 엔진 → 카드팩)
config.js               제목·색·로고·모드·말 개수 등 설정 (한 곳에서 변경)
assets/logo.svg         임시 로고

engine/                 게임 엔진 — 주제와 무관, 카드팩을 바꿔도 그대로
  core.js               카드팩 등록, 난수, 카드 더미, 판 만들기/자동 배치, 카드팩 검사
  game.js               규칙: 이동, 칸 판정, 카드 결과·점수 계산, 되돌아보기, 차례, 결과 요약 (DOM 없음)
  ui.js                 화면: 시작, 판 그리기, 주사위, 카드 창, 결과
  sound.js              효과음 (Web Audio로 직접 합성, 소리 파일 없음)
  loader.js             설정과 링크 값을 읽어 카드팩 파일을 불러오고 시작
  style.css             디자인 (색은 config.js theme 값을 사용)

packs/                  카드팩 — 주제별 데이터만
  media-literacy/
    pack.js             주제 목록, 칸 그림, 점수 이름, 되돌아보기·선생님 칸 문구, 결과 칭호
    cards.js            카드 59장 (딜레마 33, 돌발 퀴즈 13, 돌발 상황 13)
    board.js            칸 배치 (40칸, 25칸)
  template/             새 카드팩을 만들 때 복사할 틀

tests/simulate.js       엔진 점검 + 진행 시간 추정 (node tests/simulate.js)
```

## 게임 규칙 (엔진 기준)

| 요소 | 동작 |
|---|---|
| 주사위 | 1~6 (config.js `dieFaces`로 변경), 굴러가는 효과음 |
| 사건 칸 | 업로드/다운로드·선생님 칸을 뺀 모든 칸. 딜레마 / 돌발 퀴즈 / 돌발 상황 (board.js `fill`) |
| 딜레마 | 3지선다, 정답 없음. 나올 때마다 선택지 순서를 섞음. 고른 뒤 "이유 말하기"를 하면 판단력 +1 |
| 바꿔 끼우는 카드 | `{who}`, `{where}` 조각을 무작위로 채움. 조각에 따라 선택지 결과가 달라짐(`by`) |
| 업로드 / 다운로드 | 도착하면 바로 이동. 업로드는 사다리를 천천히 오르며 환호, 다운로드는 빙글빙글 떨어지며 좌절 효과음 |
| 되돌아보기 | 신뢰를 잃고 미끄러지면 다음 차례 시작에 등장. 설명하면 신뢰 +1, 통과해도 벌점 없음 |
| 선생님께 질문하기 | 선생님이 질문하고 평가 버튼을 누름 |
| 점수 | 신뢰(주 점수), 판단력(보조 점수). 0 아래로 내려가지 않음 (탈락 없음) |
| 모둠 수 | 1~8 (한 화면에서 1모둠, 2모둠... 번갈아 진행) |
| 판 배치 | 매번 새 판(기본): 업로드·다운로드 위치와 칸별 카드 종류를 게임마다 새로 배치. 구간마다 하나씩, 출발 칸끼리 3칸 이상 간격 / 고정 판 |
| 카드 기억 | 이 기기에 나온 카드 번호만 저장하고, 다음 판에는 안 나온 카드부터 뽑음. 시작 화면에서 기록 지우기 |
| 끝 | 모든 말이 도착하면 끝. 선생님은 언제든 '끝내기'로 결과 화면 이동 |
| 결과 | 말별 점수·칭호, 만난 주제, 고른 선택 목록, 마무리 질문 |

카드 결과로 이동한 칸에서는 다시 카드가 나오지 않습니다(연쇄 없음).

## 새 카드팩 만들기

1. `packs/template` 폴더를 복사해 이름을 바꿉니다. (예: `packs/environment`)
2. 세 파일 안의 `'template'`을 새 폴더 이름으로 바꿉니다.
3. `cards.js`에 카드를, `board.js`에 칸 배치를 채웁니다. 배치를 비워 두면 자동 배치됩니다.
4. `config.js`의 `pack` 값을 바꾸거나 링크에 `?pack=environment`를 붙입니다.
5. `node tests/simulate.js environment`로 카드 형식 오류와 예상 진행 시간을 확인합니다.

카드 형식(딜레마, 바꿔 끼우는 카드, 퀴즈, 돌발 상황)은 `packs/media-literacy/cards.js` 맨 위 주석에 정리되어 있습니다.

주사위 15초, 딜레마 90초(토의·이유 말하기 포함), 퀴즈 35초, 돌발 상황 12초, 선생님 칸 60초로 가정한 값입니다.

| 2개 | 약 16장 | 약 21분 |
| 3개 | 약 24장 | 약 31분 |

압축 25칸은 말 2개 약 12분, 4개 약 24분입니다. 기본 말 개수는 2개입니다.
