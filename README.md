# 업다운 로드

초등 5~6학년 디지털 미디어 리터러시 수업용 보드게임입니다.
전통 뱀사다리놀이를 디지털 세계로 옮겼습니다. 지름길은 사다리를 타고 오르는 "업로드", 미끄럼틀은 뱀을 타고 떨어지는 "다운로드"이고, 도착하는 칸마다 딜레마·돌발 퀴즈·돌발 상황이 나옵니다.

- 카드 150장: 딜레마 80(3지선다, 정답 없음, 선택지 순서 섞기, 누가·어디서가 바뀌는 카드 15장), 돌발 퀴즈 40, 돌발 상황 30
- 고른 이유를 말하면 판단력 점수, 신뢰를 잃고 미끄러지면 되돌아보기
- 기기 하나로 하기 / 학급 함께하기(모둠 태블릿 여러 대 + 선생님 전자칠판이 같은 화면)
- 로그인 없음, 개인정보 저장 없음

## 쓰는 방법

### 기기 하나로 하기
`index.html`을 열고 "기기 하나로 시작". 인터넷 없이도 됩니다.

### 학급 함께하기
1. 선생님 화면(전자칠판)에서 웹 주소를 열고 "학급 방 만들기"를 누릅니다.
2. 방 번호 5자리와 QR 코드가 나옵니다. 모둠 태블릿에서 QR을 찍거나, 주소를 열고 "모둠 태블릿으로 참여하기"에 방 번호를 넣습니다.
3. 태블릿마다 자기 모둠 번호를 고릅니다. 선생님 화면에 "연결됨"이 뜹니다.
4. 선생님 화면에서 "게임 시작". 모든 화면에 같은 판이 나옵니다.
5. 차례인 모둠의 태블릿에서만 주사위와 카드 선택 버튼이 켜집니다. 다른 모둠 태블릿과 전자칠판에서는 그 모둠이 무엇을 고르는지 실시간으로 보입니다.
6. 선생님 칸 평가와 "끝내기"는 선생님 화면에서 합니다. 선생님 화면에서는 모둠 대신 버튼을 누를 수도 있습니다.

- 게임 계산은 선생님 화면에서 합니다. 게임 중에는 선생님 화면 창을 닫지 마세요. 실수로 새로 고쳤다면 처음 화면의 "이어서 하기"로 같은 방에 다시 연결됩니다.
- 모둠 태블릿은 기본으로 소리가 꺼져 있습니다(교실이 시끄러워지지 않도록). 전자칠판에서 소리가 납니다.
- 통신은 무료 공개 MQTT 중계 서버(EMQX → HiveMQ → shiftr.io 순서로 시도)를 거칩니다. 주고받는 내용은 모둠 번호, 말 위치, 점수, 카드 번호와 선택뿐입니다.
- 학교 인터넷에서 중계 서버 포트(8084, 8884)가 막혀 있으면 방 만들기가 실패할 수 있습니다. 그때는 "기기 하나로 시작"을 쓰거나, `config.js`의 `net.brokers`에 학교에서 쓸 수 있는 서버를 넣으세요.

### 웹 주소 만들기 (GitHub Pages)
GitHub Pages는 공개 저장소에서 무료입니다(비공개 저장소는 유료 요금제 필요).
1. 저장소 Settings → General → 맨 아래 Danger Zone → Change visibility → Public
2. Settings → Pages → Build and deployment → Source: "Deploy from a branch"
3. Branch: 이 작업 브랜치(또는 main에 합친 뒤 main), 폴더 `/ (root)` → Save
4. 1~2분 뒤 `https://donymany2.github.io/media-literacy-boardgame/` 에서 열립니다.

  app.js                시작 화면, 학급 방·로비·QR, 모둠 참여, 게임 진행(감독)
  loader.js             카드팩 파일을 불러오고 시작
  style.css             디자인
  vendor/               함께 넣은 라이브러리 (MQTT.js, QRCode.js, MIT)

packs/media-literacy/   카드팩 — 주제별 데이터만
  pack.js               주제, 조각(누가·어디서), 그림 연결, 점수 이름, 이유 말하기·되돌아보기·선생님 칸, 칭호, 파일 목록
  art.js                직접 그린 SVG 그림 (칸 친구들, 카드 장면)
  cards.js              카드 1차분 (59장)
  cards-2.js            딜레마 추가분 (47장)
  cards-3.js            돌발 퀴즈·돌발 상황 추가분 (44장)

## 게임 규칙 (엔진 기준)

| 요소 | 동작 |
|---|---|
| 사건 칸 | 업로드·다운로드·선생님 칸을 뺀 모든 칸. 딜레마 / 돌발 퀴즈 / 돌발 상황 |
| 딜레마 | 3지선다, 정답 없음. 나올 때마다 선택지 순서를 섞음. 고른 뒤 "이유 말하기"를 하면 판단력 +1 |
| 업로드 / 다운로드 | 도착하면 바로 이동. 업로드는 사다리를 천천히 오르며 환호, 다운로드는 뱀을 타고 떨어지며 좌절 효과음. 도착한 칸의 카드도 이어서 나옴 (한 차례에 카드 최대 2장) |
| 카드 결과로 이동 | 이동한 칸이 업로드·다운로드면 이어서 이동. 일반 카드 칸이면 카드는 다시 나오지 않음 |
| 되돌아보기 | 신뢰를 잃고 미끄러지면 다음 차례 시작에 등장. 설명하면 신뢰 +1 |
| 판 배치 | 매번 새 판(기본): 업로드·다운로드를 구간마다 하나씩, 출발 칸끼리 3칸 이상 떨어뜨려 무작위 배치 / 고정 판 |
| 카드 기억 | 이 기기(혼자 하기 기기나 선생님 화면)에 나온 카드 번호만 저장해 다음 판에는 안 나온 카드부터 |
| 모둠 수 | 1~8 |
| 말 속도 | 빠르게 / 보통 / 느리게(기본) — `config.js`의 `speeds` |

## 새 카드팩 만들기

1. `packs/template` 폴더를 복사해 이름을 바꿉니다. (예: `packs/environment`)
2. 파일 안의 `'template'`을 새 폴더 이름으로 바꿉니다.
3. `cards.js`에 카드를, `board.js`에 칸 배치를 채웁니다. 파일을 더 나누려면 `pack.js`의 `files` 목록에 적습니다.
4. `config.js`의 `pack` 값을 바꾸거나 링크에 `?pack=environment`를 붙입니다.
5. `node tests/simulate.js environment`로 카드 형식 오류와 예상 진행 시간을 확인합니다.

카드 형식(딜레마, 바꿔 끼우는 카드, 퀴즈, 돌발 상황)은 `packs/media-literacy/cards.js` 맨 위 주석에 있습니다.
